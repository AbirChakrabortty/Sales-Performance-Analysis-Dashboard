# Sales-Performance-Analysis-Dashboard

This repository features an Excel-based analytics dashboard designed to track, analyze, and visualize global retail sales data. The project relies on structured pivot tables to extract actionable insights from large transactional datasets, focusing on revenue across various categories, sub-categories, departments, and time periods.

🗂️ Project File
Sales_Performance_Pivot_Dashboard1.xlsx: The primary workbook containing the raw dataset, structured pivot tables, and the final interactive dashboard.

📊 Dashboard Components
The dashboard is powered by four primary pivot table sheets that aggregate the raw data into key performance metrics:

Pivot - Category: Analyzes total sales revenue broken down by top-level product categories (e.g., Technology, Furniture).

Pivot - SubCategory: Provides a granular view of sales performance by specific product sub-categories (e.g., Phones, Copiers).

Pivot - Department: Evaluates organizational or departmental revenue streams.

Pivot - Year: Tracks year-over-year (YoY) sales growth and historical revenue trends (e.g., 2012 vs. 2013 performance).
